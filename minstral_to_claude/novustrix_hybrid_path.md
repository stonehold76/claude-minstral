# Novustrix Hybrid Path

## Goal
Build Novustrix as a Matrix client for Cognitive Cosmos while pushing its features into Matrix standards.

---

## 📅 Phases

### Phase 0: Foundations (0-3 Months)
- Widget host + SDK (Flutter)
- PostMessage protocol
- Security tests
- Discord-like UI
- Bug reporting + Widget Workshop
- Deploy test homeserver

**Output:** Alpha for internal testing.

---

### Phase 1: Novustrix-First (3-12 Months)
- Roles (client-side)
- Voice captions
- Studios (Visual Artistry, The Anvil, Audio, The Hearth)
- Cross-Arts Bus
- Modmail
- Qualification Gate + Great Repository
- Alexandria snippet import

**Output:** Beta for Cognitive Cosmos migration.

---

### Phase 2: Standardization (6-18 Months)
- Draft **Matrix Specification Changes (MSCs)** for:
  - Widget API extensions
  - Roles (`m.role` event)
  - Studios (`m.room.type: "m.studio"`)
  - Cross-Arts Bus (`m.widget.bus`)
- Engage Matrix community.

---

### Phase 3: Hybrid (12-24 Months)
- Support **both** Matrix standards + Novustrix extensions.
- Graceful degradation for other clients.

---

### Phase 4: Adoption (18-36 Months)
- Drive MSC adoption in Element, FluffyChat, etc.
- Build community (`#novustrix:matrix.org`).

---

## 🔗 Principles
- **Backward compatible:** Use standard Matrix events + extensions.
- **Secure:** Server-side proxy + qualification gate.
- **Performant:** Lazy-load widgets, rate limits.
